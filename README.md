# 20243006996 - ResponsiveLayout1

Practical 1: Creating Responsive Android User Interfaces

## Part 1 - LinearLayout with Weights
- Implemented using nested LinearLayout with layout_weight
- Vertical distribution: weight 2:1:1:2:1
- Horizontal color blocks: equal weight 1 each

## Part 2 - ConstraintLayout with Weights
- Implemented using ConstraintLayout with chains and constraints
- Same visual output as Part 1
- Uses constraint-based positioning instead of nested LinearLayout

## Project Structure
- LinearLayoutVersion/ - Part 1 project
- ConstraintLayoutVersion/ - Part 2 project

Both projects can be opened directly in Android Studio.
